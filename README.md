## Publish on GitHub Pages
1. Create a new public repository on GitHub (for example `ged108-portfolio`).
2. Upload everything in this folder to the repo root (index.html must be at the top level).
3. Go to Settings, then Pages. Under Source choose "Deploy from a branch", pick `main` and `/ (root)`, then Save.
4. Wait 1 to 3 minutes. Your link will be `https://YOUR-USERNAME.github.io/ged108-portfolio/`.
5. Open the link on your phone and laptop and click every nav button before you submit.
